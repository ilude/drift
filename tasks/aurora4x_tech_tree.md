# Aurora 4X Tech Tree Reference

- Extracted from the Aurora 4X tech tree overview image
- Technologies are organized by research category (color-coded bands), then roughly left-to-right by research tier/progression order
- Stats shown where legible from the source image
- **Note on accuracy:** The source image is approximately 2000×1190 pixels encoding 500+ individual tech nodes at ~6–8px font size. Many intermediate tier names and exact values are partially inferred. For complete accuracy, cross-reference with the [Aurora 4X wiki](https://aurora2.pentarch.org/), the in-game tech browser, or extract directly from `TN.db` (Aurora stores all tech data in SQLite)

---

## Formatting Conventions

- `→` denotes an ordered progression chain
- `/` denotes parallel variants (e.g. Standard / Blue / Alien)
- **Tiers 1–N** means a numbered series with N confirmed tiers
- **Tiers 1–N+** means the series continues beyond what was legible in the source
- ***(partial data)*** means only some values were readable from the source image
